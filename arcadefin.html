ArcadeFin

2025 Web App / PWA Client-Side Encrypted

About This Project

ArcadeFin is a modern, responsive personal finance tracking web application designed to help users seamlessly manage their daily transactions, multiple custom wallets, and monthly budgets.

Engineered with a clean, fintech-inspired interface, the application provides an intuitive dashboard for real-time financial monitoring while prioritizing user privacy through client-side data encryption.

Key Features

  • Multi-Wallet Dashboard: Comprehensive dashboard for tracking total wealth, income, and expenses across isolated custom wallets.
  • Interactive Monthly Budgeting: Real-time progress bars, remaining balance calculations, and instantaneous overbudget alerts.
  • Advanced Transaction Logging: Horizontal date-strip filtering, granular search, and dynamic category tracking.
  • Secure Localized Encryption: Zero-knowledge client-side data encryption powered by CryptoJS to protect sensitive financial records before syncing.
  • Data Portability & Recovery: Full user sovereignty with encrypted JSON backup and restore functionalities.
  • Responsive Glassmorphism UI: Mobile-first design with smooth Dark/Light theme switching and Progressive Web App (PWA) mechanics for offline resilience.
