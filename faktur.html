Coretax e-Faktur Data Automation Pipeline
2026 Automation

About This Project

An automated data processing workflow built during my Accounting & Tax internship at PT Bank Central Asia Tbk (BCA) to streamline tax invoice (e-Faktur) preparation for Indonesia's Coretax system. Designed as a one-click solution using dynamic folder path configurations, the pipeline consolidates multi-category raw transaction exports, enriches missing records via multi-tier master database lookups, synchronizes master data updates, and generates formatted Excel summaries alongside Coretax-compliant outputs—eliminating repetitive manual data entry and ensuring consistent tax reporting accuracy.

Key Features

  • One-Click Dynamic Folder Execution
  • Multi-Tier Master Database Lookup
  • Automated Master Data Sync (Insert & Update)
  • Structured Summary & Coretax Formatting
